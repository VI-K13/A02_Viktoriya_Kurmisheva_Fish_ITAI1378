## Project Overview

For this assignment, our group selected the **Kingdom of Image Formats** and completed **Challenge 1: The Royal Banquet Menu**. We created a royal-themed menu in which four meals represent four common image formats:

- **JPEG Pizza** – The Shareable Slice
- **PNG Parfait** – Layers of Transparency
- **BMP Burger** – The Big Bitmap Feast
- **TIFF Royal Cake** – The Print Specialist

The menu explains the best uses, strengths, and trade-offs of each image format. We also created a short Canva presentation that provides additional information about image formats and their connection to computer vision.

## Connection to Computer Vision

Image formats affect how images are stored, compressed, processed, and analyzed. Lossy compression can remove visual details, while lossless formats preserve more of the original image data. These differences can influence the quality of images used in computer-vision tasks such as object detection, image classification, and image analysis. Choosing an appropriate format can help preserve important visual information while balancing image quality and file size.

## Key Takeaway

There is no single image format that works best for every situation. JPEG, PNG, BMP, and TIFF provide different balances of file size, image quality, transparency, compression, compatibility, and professional use. Understanding these differences is important when selecting images for websites, editing, printing, storage, and computer-vision applications.
